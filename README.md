# Universal-Web-Agent

**Versatile AI-powered web agent** using **Playwright + LangGraph** for autonomous internet tasks.

## Features
- Full browser automation (navigate, click, type, scroll, extract data)
- LLM-powered reasoning and planning
- Tool system for complex tasks
- Ready for extensions (stealth, proxies, memory, UI)

## Quick Start

```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env   # add your API key
python main.py
